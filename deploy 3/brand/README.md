# MPASS Law Group — Brand & Logo Package

The mark: a gold **diamond** (the *impasse* / obstacle) with a paper airplane and a
tapering contrail flying *around* it — MPASS is how you get past the impasse.
"MPASS" also carries the initials of Steven's children.

**Brand colors**
- Navy (primary): `#0B1A2E`
- Gold (accent): `#C69A4C`
- Steel (secondary): `#5D7186`
- Cool off-white: `#F4F6F8`

**Type**
- Headlines: **Newsreader** (serif)
- Text / UI: **Archivo** (sans)

---

## What's inside

**/vector** — master files, infinitely scalable (open in a browser, Illustrator, Canva, Inkscape).
- `mark-gold.svg`, `mark-navy.svg`, `mark-white.svg`, `mark-gold-on-navy.svg` — the symbol only
- `logo-horizontal.svg` / `-reversed.svg` — mark + wordmark, side by side (reversed = for dark backgrounds)
- `logo-stacked.svg` / `-reversed.svg` — mark above wordmark

**/png** — ready-to-use raster (transparent where noted).
- `mark-gold-256/512/1024/2048.png` (transparent), `mark-navy-1024`, `mark-white-1024`
- `logo-horizontal-navy.png`, `logo-horizontal-white.png`, `logo-stacked-navy.png`

**/favicon** — browser-tab icons (gold on navy, rounded): 16, 32, 48, 180 (Apple touch), 512.

**/social**
- `avatar-navy/white/gold-1000.png` (+ .svg) — square profile pictures
- `banner-x.png`, `banner-linkedin.png`, `banner-facebook.png` — cover images (SVG masters also included at exact platform sizes)

**/stationery**
- `letterhead.svg` (US Letter print master) + `letterhead-preview.png`
- `business-card-steven.svg`, `business-card-chad.svg`, `business-card-back.svg` (3.5×2 in print masters) + `.png` previews

**email-signature.html** — open in a browser, copy the block into your email client's signature editor.

---

## Notes
- The **.svg** files are the true masters — use them for anything printed or resized large. Any print shop or design tool can output PDF/EPS/PNG at any size from these.
- The **.png** lockup/banner/card/letterhead files are convenience exports; for large-format print, export fresh from the matching `.svg`.
- Fonts (Newsreader, Archivo) are free on Google Fonts — install them before editing the vector wordmarks.
